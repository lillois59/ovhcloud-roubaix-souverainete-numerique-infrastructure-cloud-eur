# OVHcloud Roubaix - Souveraineté Numérique & Infrastructure Cloud Européenne

Ce projet met en avant l'infrastructure cloud, la souveraineté numérique et la sécurité des données garanties par OVHcloud à Roubaix.

## Description
Landing page et documentation sur la souveraineté des données, la conformité RGPD et les centres de données OVHcloud basés en Europe.

## Features
- Présentation des infrastructures OVHcloud Roubaix
- Explication des garanties de souveraineté numérique européenne
- Conformité RGPD et sécurité des infrastructures cloud
